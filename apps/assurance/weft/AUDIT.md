# AUDIT — Weft

## Threat model

Assets: the bundle (assertions, artifacts, links, sign-offs), the manifest. Adversaries: someone editing evidence after sign-off; someone padding a bundle with unexplained files; a forged or edited manifest; a hostile import.

| Threat | Control | Residual |
|---|---|---|
| Evidence edited, re-dated or renamed after sign-off | Binding hash v2 over statement + period + sorted `{id, capturedOn, sha256}` of linked evidence; recomputed on every render; `invalid-signoff` finding and header marker | Hash ≠ signature: no key binds the reviewer identity |
| Assertion appended or removed after the manifest | `verifyManifest` reports `addedAssertions` / `missingAssertions`; `intact` requires both empty (parent-review fix) | — |
| Evidence swapped for a same-named file | Content hashes, not names; `declaredSha256` comparison | Only when a declared hash was recorded at collection |
| Padding the bundle | `orphan-artifact` for unlinked artifacts; `duplicate-content` for renamed copies | — |
| Backdating / out-of-window evidence | Inclusive period check per link; weak vs supported status | Dates only, no timestamps |
| Forged manifest | `root` recomputed from entries + bindings; `rootMatches=false` when the manifest itself was altered | A forger who recomputes the root is not detectable without signatures |
| Hostile import | 2 MiB UTF-8 cap checked before `JSON.parse`; ≤ 300 artifacts / 200 assertions / 2000 links / 50k chars; hex validation; strict calendar dates (`2026-02-30` rejected in `asOf`, `periodStart`, `periodEnd`, `capturedOn`, `signedOn`, `generatedOn` — pinned by `tests/validation.test.ts`); the validator reads named keys only and never recurses into unknown structure, so a 20 000-deep nesting is reported at the field path without a stack overflow (tested); path-addressed issues; a committed synthetic sample (`qa/samples/invalid-bundle-calendar-date.json`) exercises the refusal through the UI | Bespoke validator |
| CSV formula injection (October 2026 exports) | `src/engine/csv.ts`: a cell beginning with `= + - @` (even behind leading whitespace/control characters) or with a tab/CR is prefixed with `'`; every cell double-quoted, quotes doubled, CRLF rows; hostile artifact ids/names are pushed through `analyze()` in `tests/csv.test.ts` and no written cell may start with a formula character | Consumers that strip the quote prefix differently may still interpret a cell |
| XSS | React escaping; no `innerHTML`; CSP `script-src 'self'` | `style-src 'unsafe-inline'` |

## Data flow

Fixture → validator → state → `analyze` (pure) → DOM. Manifest/bundle imports via size-gated `FileReader` → validators → `verifyManifest` / `diffBundles`. Exports via Blob URL (`downloadText`): bundle JSON, manifest JSON, analysis JSON, and — since October 2026 — the findings ledger and artifact table as formula-safe CSV (`toCsv(findingsToCsvRows(...))`, `toCsv(artifactsToCsvRows(...))`). The CSV export adds no import path. No network or storage APIs.

## Security headers (vercel.json)

Lab-wide canonical set (October 2026 upgrade round), applied to `/(.*)` with `cleanUrls: true`:

- `Content-Security-Policy: default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self'; manifest-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'; object-src 'none'`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy: no-referrer`
- `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=()`
- `Cross-Origin-Opener-Policy: same-origin`
- `Cross-Origin-Resource-Policy: same-origin`
- `Strict-Transport-Security: max-age=63072000; includeSubDomains`

`form-action 'none'` is compatible with this app: every `<form>` (add assertion, add artifact, sign-off) calls `preventDefault()` and never navigates. `style-src 'unsafe-inline'` remains for React inline style attributes. Headers apply to the static Vercel deployment only, not to `vite preview`/dev.

## Dependency findings

`npm audit --audit-level=high`: 0 (re-measured after the October 2026 toolchain bump to Vite 7.3 / @vitejs/plugin-react 5.2; lockfile regenerated by npm and reproduced with `npm ci` — see `EVIDENCE.md`). Runtime deps: react, react-dom, two OFL font packages.

## Unresolved limitations

No cryptographic signatures (an obvious production step: sign the manifest root); text artifacts only; single-user; periods are calendar dates; automated a11y only. The two October 2026 CSV buttons reuse existing button styles and tokens but were not browser-audited in this round (no Playwright/axe run was performed from this repository); the `qa/` screenshots predate them.
